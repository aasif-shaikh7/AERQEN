# AERQEN — Brand Guide

**Version:** 1.0  
**Brand Status:** Working Brand Identity  
**Product:** AI Computer Employee  
**Tagline:** One Agent. Every Workflow.

## 1. Brand Name

### AERQEN
Pronunciation: **Air-ken**

AERQEN is an invented technology name designed to remain broad enough for computer automation, browser workflows, Office work, coding, research, specialist applications, memory, and multi-agent workflows.

Always write the brand as **AERQEN**. Technical identifiers may use lowercase: `aerqen`.

## 2. Product Definition

**AERQEN is an AI Computer Employee designed to understand tasks, plan workflows, use approved computer tools, verify results, recover from failures, and assist with a wide range of digital work.**

Short description:

> An AI employee for computer-based work.

One-line description:

> AERQEN turns natural-language instructions into controlled, verifiable computer workflows.

## 3. Tagline

### Primary
> **One Agent. Every Workflow.**

Supporting messaging:
- Think. Act. Verify.
- From Intent to Execution.
- Your Digital Work Partner.
- AI That Gets Work Done.

Use the primary tagline as the default. Do not stack all taglines together.

## 4. Brand Positioning

AERQEN is a **general-purpose AI computer employee**, not merely a chatbot, browser bot, RPA macro tool, coding assistant, Revit plugin, or Office automation script.

Specialized capabilities are modules inside the broader AERQEN platform.

> AERQEN is a general-purpose AI computer employee that combines reasoning, planning, controlled tool execution, computer interaction, observation, verification, memory, and security into one extensible platform.

## 5. Brand Personality

AERQEN should feel:
- Intelligent
- Reliable
- Calm
- Professional
- Capable
- Transparent
- Practical
- Secure
- Modern
- Engineering-focused

Avoid a childish, gimmicky, overly robotic, aggressive, or misleading identity.

## 6. Communication Style

AERQEN communicates clearly and directly. It should:
- explain what it is doing
- distinguish plans from completed actions
- report failures honestly
- ask for approval when required
- avoid unnecessary jargon
- provide actionable information

**Core rule:** Never claim success without verification.

## 7. Logo Concept

The logo should represent:

**AI + Intelligence + Workflow + Execution**

Suggested direction:
- geometric `A`
- central node representing the AI core
- connected lines representing tools/workflows
- subtle forward direction representing execution

The logo should be minimal, geometric, scalable, recognizable at small sizes, and suitable for software UI, GitHub, website favicon, and desktop application icon.

Avoid generic robot heads, generic brains, excessive complexity, or tiny details.

## 8. Color Direction

Recommended visual direction:
- Primary: deep dark/near-black foundation
- Accent: distinctive electric blue, cyan, violet, or blue-violet family
- Neutral: white, light gray, dark gray

Do not lock final hex values until the visual identity is approved.

## 9. Typography

Preferred modern sans-serif directions:
- Inter
- Geist
- IBM Plex Sans
- Manrope

The logo wordmark may use a customized geometric sans-serif treatment.

## 10. Product Naming System

- **AERQEN Core** — reasoning, orchestration, task management
- **AERQEN Agent** — general-purpose task execution
- **AERQEN Vision** — screen understanding and visual observation
- **AERQEN Tools** — controlled integrations
- **AERQEN Memory** — user, project, and task context

- **AERQEN Browser** — browser workflows
- **AERQEN Office** — documents, spreadsheets, presentations
- **AERQEN Code** — programming, debugging, testing

## 13. Brand Promise

> **If AERQEN says a task is complete, it should be able to explain what it did and how the result was verified.**

## 14. Trust Principles

AERQEN must prioritize:
1. Truth
2. Safety
3. Verification
4. User control
5. Transparency
6. Reliability
7. Privacy
8. Recoverability

The AI must never hide an error merely to appear successful.

## 15. Human-in-the-Loop

AERQEN is an employee-like system, not an uncontrolled autonomous process.

The user remains in control of high-impact actions.

Confirmation should be required before:
- deleting important files
- irreversible changes
- external communication
- financial transactions
- account/security changes
- sensitive data transfer
- potentially destructive system operations

## 16. Brand Usage

Correct:
- AERQEN can create and verify an Excel report.
- Install AERQEN.
- AERQEN Agent planned the workflow.
- AERQEN Vision verified the application state.

Avoid:
- Aerqen AI Bot
- AER-QEN Assistant
- `AERQEN™` unless trademark status has actually been established

## 17. Legal / Availability Status

AERQEN is currently a **working project brand**.

This guide does not establish:
- trademark registration or clearance
- domain ownership
- company registration
- app-store ownership
- GitHub organization ownership

Before public commercial launch, perform appropriate trademark, domain, GitHub, app-store, and jurisdictional legal checks.
